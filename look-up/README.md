# MetaFox｜抬头看镜头

44 张 PNG 分组图，覆盖 217 个角色。前 43 组每组 5 个角色，第 44 组为 221、222 两个角色。

素材说明：镜头从上方俯拍，角色抬头看镜头并做可爱动作。

## 目录与命名

- `groups/`：分组图片，命名为 `group-组号_角色编号列表.png`，例如 `group-01_001_002_003_004_005.png`。
- [groups.csv](groups.csv)：按组查找，包括角色编号、实际尺寸、新路径与原文件名。
- [characters.csv](characters.csv)：按角色编号查找，包括组号、图内位置和原三视图路径。
- [manifest.json](manifest.json)：完整编号映射、原文件名、文件大小、SHA-256 与 Git Blob SHA-1。

CSV、JSON 中的路径均相对于本目录。全部图片为 1536 × 1024，文件内容与原始 PNG 完全一致。

图内编号顺序依据源索引：左上 → 中上 → 右上 → 左下 → 中下；最后一组为左上、中上两只。
原始编号 018、021、111、158、165 无源素材，因此没有对应角色。

原三视图位于仓库根目录的各编号文件夹，例如 [001/001.png](../001/001.png)。
